# BiswaPath · বিশ্বপাঠ

Free, bilingual (Bengali/English) learning and guidance for Bengali-speaking students worldwide.
Founder: Dr Sumit Konar.

- `site/` – the published website (plain HTML/CSS, fonts self-hosted). Cloudflare Pages serves this folder.
- `build.py` – regenerates the pages in `site/` (`python3 build.py`).
